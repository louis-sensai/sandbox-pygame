# Snake Game in Pygame

A simple snake game built with Pygame.

## Installation

Make sure you have Python 3.6+ installed, then install pygame:

```bash
pip install pygame
```

## How to Play

- **Arrow keys**: Move the snake (Up, Down, Left, Right)
- **Q**: Quit the game
- **C**: Play again after game over

## Features

- Circle-shaped apple
- Dark gray background (22, 22, 22)
- Score tracking
- Game over screen with quit option

## Controls

| Key | Action |
|-----|--------|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |
| Q | Quit |
| C | Play again |
| ESC | Quit |
